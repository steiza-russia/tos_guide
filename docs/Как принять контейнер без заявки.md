# Как принять контейнер без заявки?

## Заполянем данные о контейнере

Переходим на страницу "Контейнеры". Нажимаем "Действия" -> "Принять без заявки" и заполняем поля

![Находим контейнер](/images/48.png)

1. Клиент (Обязательно)
2. Терминал (Обязательно)
3. Номер контейнера (Обязательно)
4. ISO код обязательно
5. Тип (автоматически)
6. Размер (автоматически)

И нажимаем на кнопку "Создать акт прием". После этого система автоматически перекинет на черновик акта приема

![Находим контейнер](/images/49.png)

## Заполняем все необходимые поля

1. Линия (обязательно, особенно если есть CODECO)
2. Сток
3. Номер автомобиля (Важно для CODECO)
4. Имя водителя (Важно для CODECO)
5. Добавляем повреждения, если они есть
6. Прикрепляем фото, если нужно

После этого нажимаем "Сформировать акт"

![Находим контейнер](/images/50.png)

После этого контейнер будет в статусе "На терминале"
