# Как создать клиентский тариф?

1. Заходим в раздел "Клиенты"
2. Находим нужного клиента и переходим в его карточку

![Находим контейнер](/images/78.png)

3. Находим раздел "Тарифы"

Здесь отображаются все базовые услуги на терминале. Каждой услуге можно назначить тариф с ограниченным промежутком времени

4. Нажимаем "+" на нужной услуге, чтобы добавить тариф

![Находим контейнер](/images/79.png)

- **Дата начала** и **Дата окончания** будут влиять на срок действия тарифа. Эта стоимость будет распространятся на контейнеры принятые в эти даты
- **Тип тарифа**: влияет на тип контейнера к которому будет применен тариф. Если выбрать вариант "Все", то на любые контейнеры. Если нужно задать тариф для 40 или 20, то нужно выбрать вариант "Свой"
- **Груженость**: Если нужно, чтобы тариф распространялся только на груженые или на порожние контейнеры
- **Стоимость**
- **Бесплатные дни**: Уникально только для хранения. В рамках этого количества дней хранение не будет начисляться

![Находим контейнер](/images/80.png)

После добавления тариф появится в списке. Если нажать на "+" рядом с датой, то можно добавить еще один специфичный тариф для другого типа контейнера

![Находим контейнер](/images/81.png)
