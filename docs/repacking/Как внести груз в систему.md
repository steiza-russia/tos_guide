# Как внести груз в систему?

1. На странице партии переходим на вкладку "Транспорт с грузом"
2. Нажимаем на кнопку "Добавить груз"

![Находим контейнер](/images/57.png)

## Заполняем поля

1. **_Номер контейнера_** - Поле необязательное, если груз приедет в контейнере
2. **_Номер транспорта_** - Номер автомобиля, на котором приедет груз
3. **_Номер пломбы_** - Необязательное поле
4. **_Вес груза, кг_** - Нетто груза, которое приедет в этом контейнре/авто. Важное поле, от него будет расчет в дальнейшем в акте, как количество груза по документам
5. **_Количество мест_** - Необзятальное поле, для груза, который можно посчитать
6. **_Номер ТТН_**

Нажимаем сохранить. Груз появится в системе, а также обновиться общая информация о количестве груза по документам
