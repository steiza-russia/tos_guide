# Как перетарить груз?

1. На странице партии переходим на вкладку "Транспорт с грузом"
2. Находим нужный груз по транспорту, номеру документа или пломбе
2. Нажимаем на кнопку "Действия" -> "Перетарить"

![Находим контейнер](/images/60.png)

## Заполняем форму

1. **_Номер контейнера_** - Поле необязательное. Это контейнер, в который будет перетарен груз. После перетарки. В списке отображаются только порожние контейнеры в системе. После выбора, будет отображаться инормация о параметрах контейнера
2. **_Номер транспорта_** - Номер автомобиля, на котором уедет груз
3. **_Нетто груза, кг_** - Нетто груз, которое перетаривается. при изменении этого поля автоматически пересчитается поле брутто
4. **_Вес оборудованной тары, кг_** - Вес тары. Это либо вес тары контейнера с дополнительной тарой, либо вес автомобиля, если без контейнера
5. **_Брутто груза, кг_** - Вес нетто + вес тары. При изменении этого поля, автоматически пересчитается поле нетто
6. **_Количество мест_** - сколько мест перетарили
7. **_Номер пломбы_** - Если пломба не нужна, можно поставить прочерк

![Находим контейнер](/images/61.png)

## Переходной контейнер

Если в контейнер дотаривается груз, то система отобразит, сколько груза уже затарено в контейнер

![Находим контейнер](/images/62.png)

Если попытаться положить груза больше, чем позволяет контейнер, то система предупредит, но не запретит добавить груз

![Находим контейнер](/images/63.png)

Также система предупредит, если попытаться перетарить больше нетто, чем осталось в транспорте. Но не запретит затарку

![Находим контейнер](/images/64.png)
