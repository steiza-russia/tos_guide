# Управление сотрудниками

## Создание сотрудника

1. Переходим на страницу "Пользователи" -> "Сотрудники"
2. Нажимаем на кнопку "Добавить сотрудника"

![Находим контейнер](/images/69.png)

3. Заполняем поля
4. Нажимаем "Далее"

> Пароль важно запомнить и передать сотруднику. Увидеть пароль в системе не получится. Сотрудник самостоятельно сможет его потом поменять или администратор

![Находим контейнер](/images/70.png)

5. Выбираем терминал, к которому нужно дать доступ

![Находим контейнер](/images/71.png)

6. Выбираем должность и проставляем необходимые права

![Находим контейнер](/images/72.png)

## Описание прав

##### Заявки

| Название пункта           | Что дает                                                          |
| ------------------------- | ----------------------------------------------------------------- |
| Создание заявок на прием  | Создавать заявку на прием в разделе "Заявки"                      |
| Редактирование заявок     | Редактировать заявки и линковать контейнеры                       |
| Просмотр заявок           | Возможность видеть список заявок и детальную информацию по заявке |
| Создание заявок на выдачу | Создавать заявку на выдачу в разделе "Заявки"                     |
| Удаление заявки           | Возможность удалить заявку в разделе "Заявки"                     |


##### Контейнеры

| Название пункта                     | Что дает                                                                                                                                                                                                                             |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Прием контейнера                    | 1. Можно создавать и формировать акт приема<br>2. Можно принимать контейнер через "Принять контейнер без заявки"                                                                                                                     |
| Выдача контейнера                   | 1. Можно создавать и формировать акт выдачи<br>2. Можно выдавать контейнер через "Выдать без заявки"                                                                                                                                 |
| Редактирование контейнера           | 1. Можно менять информацию о контейнере в карточке и в акте приема/выдачи<br><br>Поля которые можно менять<br>Сток, Линия, Код, тип, размер, Груженость, Опсаный груз, Год выпуска, net weight, tare weight, max gross, Букинг, <br> |
| Блокировка контейнера               | Возможность блокировать и разблокировать контейнер                                                                                                                                                                                   |
| Просмотр контейнера                 | 1. Возможность видеть список контейнеров и детальную информацию по контейеру<br>2. Возможность видеть список линий<br>3. Возможность экспортировать отчет о контейнерах                                                              |
| Просмотр документов контейнера      | Возможность видеть список документов контейнера в карточке и скачивать их                                                                                                                                                            |
| Добавление документов контейнера    | Возможность добавлять новые документы контейнеру в карточке                                                                                                                                                                          |
| Удалять документы контейнеру        | Возможность удалять документы контейнера в карточке                                                                                                                                                                                  |
| Просмотр списка актов приема/выдачи | 1. Видеть список актов приема/выдачи<br>2. Возможность посмотреть детальную информацию по акту                                                                                                                                       |
| Просмотр комментариев контейнера    | Возможность видеть список комментариев контейнера                                                                                                                                                                                    |
| Создание комментариев контейнера    | Возможность создавать/удалять комментарии контейнера                                                                                                                                                                                 |

##### Клиенты

| Название пункта                 | Что дает                                                                                                                                                                            |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Создание клиентов               | Создавать клиентов в системе в разделе "Клиенты"                                                                                                                                    |
| Редактирование клиентов         | Редактировать клиентов в системе в разделе "Клиенты"                                                                                                                                |
| Редактировать клиентские тарифы | Видеть раздел "Тарифы и услуги", "Тарифы на ремонт", "Хранение", "Крановые и мониторинг", "Доп услуги"<br><br>Менять/создавать тарифы клиента в разделе "Тарифы" в карточке клиента |
| Просмотр клиентов               | Возможность видеть список клиентов и детальную информацию по ним в разделе "Клиенты"                                                                                                |

##### Стоки

| Название пункта     | Что дает                                                                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Просмотр стока      | 1. Возможность видеть список стоков клиента в поле "Сток"<br>2. Возможность видеть список стоков в разделе "Стоки" в карточке клиента |
| Создание стока      | 1. Возможность создавать новый сток клиенту в карточке клиента в разделе "Стоки"                                                      |
| Редактировать стока | 1. Возможность Редактировать сток клиента в карточке клиента в разделе "Стоки"                                                        |
| Удалять сток        | 1. Возможность удалять сток клиента в карточке клиента в разделе "Стоки"                                                              |
##### Юридические лица

| Название пункта        | Что дает                                                       |
| ---------------------- | -------------------------------------------------------------- |

| Редактирование юр лица | 1. Редактировать юридические лица в разделе "Юридические лица" |
##### Сотрудники

| Название пункта            | Что дает                                                                                  |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| Создание сотрудников       | 1. Создание новых сотрудников<br>2. Назначать им роль и права на терминале                |
| Редактирование сотрудников | 1. Возможность редактировать сотрудников<br>2. Назначать текущим сотрудникам роли и права |
##### Ремонт

| Название пункта                    | Что дает                                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Просматривать список актов ремонта | 1. Видеть список актов ремонта<br>2. Видеть детальную информацию по акту ремонта                                                                                   |
| Создавать акты ремонта             | 1. Создавать акт ремонта                                                                                                                                           |
| Редактировать акт ремонта          | 1. Редактировать акт ремонта                                                                                                                                       |
| Оценивать акт ремонта              | 1. Менять статус ремонтной группы в статус Оценено<br>2. Добавлять/Удалять услуги ремонтной группе<br>3. Менять стоимость<br>4. Получать стоимость ремонтных услуг |
| Брать ремонтную группу в работу    | 1. Менять статус ремонтной группе "В работе"<br>2. Менять статус ремонтной группе "Ремонт завершен"                                                                |
| Отклонять ремонтную группу         | 1. Переводить ремонтную группу в статус "Отклонен"                                                                                                                 |
##### Терминал

| Название пункта        | Что дает                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------- |
| Создавать терминал     | 1. Создавать новые терминалы в разделе "Терминалы"                                 |
| Редактировать терминал | 1. Редактировать информацию о терминале в разделе "Терминалы" в карточке терминала |
##### Пропуска

| Название пункта       | Что дает                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| Редактировать пропуск | 1. Редактировать информацию о пропуске<br><br>Номер автомобиля, имя водителя, номер пломбы, дата въезда |
| Удалять пропуск       | 1. Удалять пропуска в безномерной заявке на выдачу                                                      |
##### Транспорт

| Название пункта          | Что дает                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| Добавлять транспорт      | 1. Добавлять новый транспорт в поле "Транспорт" в пропуске, акте приема/выдаче и в перетарке |
| Видеть список транспорта | 1. Видеть список транспорта в поле "Транспорт" в пропуске, акте приема/выдаче и в перетарке  |

| Название пункта                   | Что дает                                                                            |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| Возможность видеть список реетров | 1. Возможность видеть страницу со списком реестров и скачивать их. Раздел "Реестры" |
| Возможность создавать реестры     | 1. Возможность создавать новые реестры в разделе "Реестры"                          |
| Удалять реестры                   | 1. Возможность удалять реестры в разделе "Реестры"                                  |
