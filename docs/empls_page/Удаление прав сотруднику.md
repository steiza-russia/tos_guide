# Удаление прав сотруднику

1. Переходим на страницу "Пользователи" -> "Сотрудники"
2. Ищем сотрудника и нажимаем на его карточку

![Находим контейнер](/images/74.png)

3. Переходим во вкладку "Права"
4. Удаляем права на нужном терминале

![Находим контейнер](/images/73.png)

> У пользователя пропадет возможность видеть всю информацию в рамках этого терминала
