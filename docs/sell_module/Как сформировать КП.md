# Как сформировать КП?

> КП - коммерческое предложение на продажу контейнеров

1. Зайти на страницу списка контейнеров
2. Нажать на "Действия" -> "Сгенерировать КП"

![Находим контейнер](/images/65.png)

3. В модельном окне выбираем контейнеры, которые попадут в КП
4. Нажимаем "Сгенерировать"

Будет сгенерирован КП в формате pdf с описанием контейнеров

![Находим контейнер](/images/66.png)
