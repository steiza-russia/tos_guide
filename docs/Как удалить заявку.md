# Как удалить заявку?

1. Зайди в раздел "Заявки"
2. Найти нужную заявку, нажать на 3 точки и на кнопку "Удалить"

> Удалить можно только заявку, в которой нет пропусков

> Чтобы дать пользователю возможность удалять заявки, необходимо поставить галочку в правах "Удаление заявок"
